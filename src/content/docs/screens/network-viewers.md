---
title: Network viewers
description: Let phones, tablets and TVs on the church network watch the service in a web browser.
---

Network viewers let any device on the same network as your Mac follow the service in a web browser: a lobby TV, an overflow room, or a phone in the pew for someone who finds the main screen hard to read. Viewers can only watch. They can't control anything.

## Turn it on

1. Open the [Screens panel](/screens/screens-panel/).
2. Under **Network viewers**, turn on **Let devices on this network watch**.
3. On the device, scan the QR code with the camera, or type the address shown into a web browser.

The panel shows how many devices are watching. The same count appears in the Present status bar.

Viewers use a web browser and don’t need to install an app.

## What viewers see

Viewers see what the audience screens show: the slides, transitions, holds, the message, the countdown and live edits. Before the service starts and after it ends, they see the idle screen.

Video slides appear on viewers as a still picture rather than moving video.

If the connection drops, the viewer keeps the last slide up and shows **Reconnecting…**. If it can't reconnect, it says **Can't reach Guidepost** and asks the person to check they're on the church Wi-Fi, with a **Try again** button.

## Turning it off

By default, network viewers turn off when you end live. To keep them on, turn off **Turn off when you end live** in the Screens panel, or click **Keep on** in the notice after ending live.

**Settings › Network › Advanced** has more options:

- **Port**: change this only if another app is already using it. Viewers need to reload after a change.
- **Start when Guidepost opens**: viewers can connect any time, and see the idle screen until you go live.
- **Turn off when you end live**.

## If viewers can't connect

**Settings › Network** shows whether the Mac is reachable, with **Check again**. If devices can't connect:

1. **Same network.** The device must be on the same network as the Mac. Guest Wi-Fi networks are often kept separate.
2. **Firewall.** Allow Guidepost through the Mac's firewall in **System Settings › Network › Firewall**. Click **Open Firewall settings**.
3. **Local Network access.** Give Guidepost permission in **System Settings › Privacy & Security › Local Network**. Click **Open Privacy settings**.
4. **Client isolation.** Some routers stop devices on the same Wi-Fi from seeing each other. Ask whoever manages the church network to turn this off for the network your viewers use.
