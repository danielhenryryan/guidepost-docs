---
title: Moving a presentation to another Mac
description: Copy a presentation to another Mac, check its fonts and screens, and share Library items.
---

You can prepare a service on one Mac and run it on another, such as an office Mac and a sanctuary Mac.

## Copy the presentation file

A saved `.guidepost` file includes its slides, themes, images and videos. There's no separate export step. Transfer the file to another Mac using:

- a USB drive;
- AirDrop;
- a shared folder, such as iCloud Drive, so both Macs see the same file.

Open the `.guidepost` file on the other Mac.

## Opening a file from another Mac

- **Media** plays straight from the file. If the file brings images or videos that this Mac's Library doesn't have, Guidepost offers to add them: **Add N items to Library** or **Not now**. Either way, the presentation works.
- **Fonts:** if the presentation uses a font this Mac doesn't have, Guidepost tells you once, shows a similar font instead, and keeps your original choice in the file. The original reappears on any Mac that has it. Fonts that come with Guidepost are always available.
- **Screens** are set per Mac. The sanctuary Mac remembers its own projector and TVs.

## Reusing slides from another presentation

To bring a few slides from an older presentation into this one, choose **Presentation › Add Slide › Import Slides from Another Presentation…**, choose the file, choose the slides, and click **Add N slides**.

## Previewing files in Finder

In Finder, a presentation's icon shows its first slide. Select a file and press <kbd>Space</kbd> to see every slide with Quick Look, without opening Guidepost.

## Sharing songs and themes

Songs and themes live in each Mac's Library. To use the same songs or themes on another Mac, export them and import them there:

- **Songs:** **Export** in **Library › Songs** saves ChordPro or OpenLyrics files. See [Importing songs](/library/importing-songs/).
- **Themes:** **Export** in **Library › Themes** saves a theme file. See [Themes](/design/themes/#share-themes).
- **Saved slides:** **Export** in **Library › Saved slides**.

A presentation file already includes the themes it uses, so you only need to share themes you want to use in new presentations.
