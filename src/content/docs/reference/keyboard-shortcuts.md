## Present

These single keys work only in Present, and not while you're typing in a field.

| Action | Keys |
|---|---|
| Next slide | <kbd>Space</kbd>, <kbd>→</kbd>, <kbd>↓</kbd>, <kbd>Page Down</kbd> |
| Previous slide | <kbd>←</kbd>, <kbd>↑</kbd>, <kbd>Page Up</kbd> |
| First slide, last slide | <kbd>Home</kbd>, <kbd>End</kbd> |
| Go to slide | Type the number, then <kbd>Return</kbd> |
| Blank | <kbd>B</kbd> |
| Logo | <kbd>L</kbd> |
| Freeze | <kbd>F</kbd> |
| Clear text | <kbd>C</kbd> |
| Message (opens the composer) | <kbd>M</kbd> |
| Add scripture | <kbd>S</kbd> |
| Add song | <kbd>W</kbd> |
| Send cue | <kbd>⇧⌘C</kbd> |
| Play or pause video | <kbd>K</kbd> |

| Return to anchor passage | <kbd>R</kbd> |

In the Scripture and Song pickers and in Search while live, <kbd>Return</kbd> is **Add & Show** and <kbd>⌥Return</kbd> is **Add**.

| Action | Keys |
|---|---|

## Presenter clickers

Clickers that send Page Up and Page Down, or the arrow keys, work without setup. A clicker's "black screen" button blanks the screen, and its "start slideshow" button goes live and, pressed again, ends live.

## Change a shortcut

1. Open **Settings › Shortcuts**.
2. Click the key you want to change, then press the new keys.
   - Press <kbd>Esc</kbd> to cancel, or <kbd>Delete</kbd> to remove the shortcut.
   - Click **+** to give an action a second shortcut.
3. To go back to the original keys, click the reset button on the row, or **Reset all…** for everything.

A few rules apply:

- Single keys without <kbd>⌘</kbd> or <kbd>⌃</kbd> can only be used for Present actions (and Blank).
- Keys that macOS uses, such as <kbd>⌘Tab</kbd> or <kbd>⌘Space</kbd>, can't be used.
- If a key is already used by another action, Guidepost explains and asks before reassigning it.

Changes apply right away, in menus, the Present key hints and **Help › Keyboard Shortcuts**.
